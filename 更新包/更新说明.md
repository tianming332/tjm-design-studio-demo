# TJM Design Studio demo · 更新包 2026-10-17

把 `tjm-design-studio-demo/` 里的文件按相同路径覆盖到仓库根目录，然后提交推送。只覆盖、不删除文件。

## 改动

- **七家服务商**：Gemini、OpenAI、Claude、智谱 GLM、DeepSeek、通义千问、豆包。「设置 · AI」会列出全部七家，Agent 可以用任意一家；生图可以用 Gemini、OpenAI、GLM、千问或豆包。
- **Key 改成 Key 池**：新增迁移 0006。以前保存在浏览器里的 Gemini、OpenAI、Claude Key 会自动并入，不用重新填。
- **修复报错**：任务快结束时系统会自动补一次画布预览。这次预览的结果现在以文字形式发给模型，不再出现 GPT 的「No tool call found for function call output」报错。
- **Skill 细化**：
  - 局部替换：换主体之前先分析原主体，替换后羽化边缘、和四周融合，再检查接缝。
  - 分层拆解：先把画面元素分成文字、艺术字、主体、装饰、背景、特效、调色几类，再拆。有豆包 Key 时优先用 AI 拆层。
- **触屏与触控笔（iPad / 手机）**：
  - 自动识别平板和手机，切换成对应的触控布局，按钮和点击区域都加大了。
  - 第一次触摸时自动全屏。iPhone 的网页无法全屏，会提示用「添加到主屏幕」打开；新增的 manifest 文件让添加到主屏幕后直接全屏运行。
  - 防止手势滑出页面：屏蔽网页缩放、下拉刷新、长按菜单，以及画布边缘的左右滑动（浏览器前进/后退）。
  - 画布手势：双指捏合缩放、双指拖动平移，双指轻点撤销，三指轻点重做。
  - 检测到触控笔后，用笔画画、手指只移动画布，避免手掌误触（可在设置里关闭）。
  - 「窗口 › 面板布局」新增「iPad 布局」和「手机布局」；「设置 · 外观」新增「触控与设备」一栏。
  - 场景工具新增「触摸绘图」「触摸编辑」，都是大按钮。
  - 手机上：工具栏移到屏幕底部，可横向滑动；面板改成从底部弹出；顶部栏压缩成一行，可横向滑动。
- **其他**：浏览器标签页图标改为白色 TJM 标志；三份 README（英文、中文、日文）的服务商表格补上了新增的四家，功能表里加了触屏一行。
